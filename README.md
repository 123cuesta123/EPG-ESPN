# ⚽ EPG ESPN - Guía de Programación XMLTV para XUI.one / XC_VM

Repositorio automatizado con **GitHub Actions** que genera y actualiza diariamente la guía de programación (**EPG XMLTV**) para todos los canales de **ESPN (LAT, MX, ARG, COL, CHI y USA)**.

## 🔗 Enlaces para tu Panel XUI.one / XC_VM

* **XML Directo (Recomendado)**:
  ```text
  https://raw.githubusercontent.com/123cuesta123/EPG-ESPN/main/epg_espn.xml
  ```
* **XML Comprimido (.gz)**:
  ```text
  https://raw.githubusercontent.com/123cuesta123/EPG-ESPN/main/epg_espn.xml.gz
  ```
